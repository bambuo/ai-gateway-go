## 二、请求处理主流程（时序图）

```mermaid
sequenceDiagram
    participant Client as Claude Code 客户端
    participant Auth as 认证层
    participant OAuth as 令牌管理
    participant Rewrite as 重写引擎
    participant Proxy as 反向代理
    participant Upstream as api.anthropic.com

    Client->>Proxy: HTTPS 请求 (含 x-api-key)

    Note over Proxy: 1. 端点路由

    alt 路径 = /_health
        Proxy-->>Client: 200 { status, oauth, clients... }
    else 路径 = /_verify
        Proxy->>Auth: authenticate(req)
        Auth-->>Proxy: clientName
        Proxy-->>Client: 200 样例重写结果
    else 其他 API 路径
        Proxy->>Auth: authenticate(req)
        Auth-->>Proxy: clientName | null

        alt 认证失败
            Proxy-->>Client: 401 Unauthorized
        else 认证成功
            Proxy->>OAuth: getAccessToken()
            OAuth-->>Proxy: access_token | null

            alt Token 过期/刷新中
                Proxy-->>Client: 503 OAuth not available
            else Token 有效
                Note over Proxy: 2. 收集请求体

                Proxy->>Rewrite: rewriteBody(body, path, config)
                Rewrite-->>Proxy: 重写后的 body

                Proxy->>Rewrite: rewriteHeaders(headers, config)
                Rewrite-->>Proxy: 清理后的 headers

                Note over Proxy: 3. 注入真实 OAuth Token

                Proxy->>Upstream: 转发请求 (含 x-api-key: OAuth token)

                Upstream-->>Proxy: 流式响应 (SSE)
                Proxy-->>Client: 流式转发响应

                Note over Proxy: 4. 审计日志
            end
        end
    end
```

## 三、重写引擎核心逻辑

```mermaid
flowchart TD
    REWRITE["rewriteBody(body, path, config)"] --> JSON{"是否为 JSON?"}
    JSON -->|"否"| PASS["原样返回 body"]

    JSON -->|"是"| ROUTE{"路由匹配"}

    ROUTE -->|"/v1/messages"| MSG["rewriteMessagesBody()"]
    ROUTE -->|"/api/event_logging/batch"| EVENT["rewriteEventBatch()"]
    ROUTE -->|"/policy_limits<br/>/settings"| GEN["rewriteGenericIdentity()"]
    ROUTE -->|"其他路径"| PASS

    subgraph Messages["/v1/messages 重写流程"]
        MSG --> M1["① 重写 metadata.user_id<br/>device_id → 标准 ID"]
        M1 --> M2["② 重写 system-reminder 块<br/>（只改 CC 注入内容，不改用户消息）"]
        M2 --> M3["③ 提取第一条用户消息文本"]
        M3 --> M4["④ 计算 CCH 哈希<br/>SHA256(salt + 字符 + version)"]
        M4 --> M5["⑤ 剥离计费头<br/>x-anthropic-billing-header"]
        M5 --> M6["⑥ 重写系统 prompt<br/>Platform / Shell / OS / 路径 → 标准值"]
    end

    subgraph Events["事件上报重写"]
        EVENT --> E1["遍历每条 event"]
        E1 --> E2["替换 device_id / email"]
        E2 --> E3["完整替换 env 对象<br/>（40+ 字段）"]
        E3 --> E4["规范化 process 指标<br/>（内存随机化）"]
        E4 --> E5["删除泄漏字段<br/>baseUrl, gateway"]
        E5 --> E6b["重写 additional_metadata<br/>（base64 解码→删除→编码）"]
    end

    subgraph Headers["请求头重写  rewriteHeaders()"]
        H1["移除 hop-by-hop 头<br/>host, connection..."]
        H2["移除认证头<br/>authorization, x-api-key<br/>（网关注入真实 token）"]
        H3["User-Agent → 标准值"]
        H4["剥离 x-anthropic-billing-header<br/>（启用跨会话缓存共享）"]
    end
```

## 四、OAuth 令牌生命周期

```mermaid
stateDiagram-v2
    [*] --> 检查缓存: initOAuth(config)

    检查缓存 --> 直接使用: Access Token 有效<br/>（过期 > 5min）
    检查缓存 --> 立即刷新: Token 缺失或已过期

    直接使用 --> 运行中: 缓存 Token
    立即刷新 --> 运行中: 调用 platform.claude.com

    state 运行中 {
        [*] --> 服务请求: getAccessToken() 被调用
        服务请求 --> 返回Token: 未过期
        服务请求 --> 返回null: 已过期（等待刷新）
        --
        定时刷新: setTimeout<br/>（过期前 5min）
        定时刷新 --> 刷新成功: POST /v1/oauth/token
        定时刷新 --> 重试: 刷新失败，30s 后重试
        刷新成功 --> 定时刷新: 重新调度
        重试 --> 定时刷新: 重新调度
    end

    note right of 直接使用
        零网络调用
        即时启动
    end note

    note right of 运行中
        网关集中管理
        客户端无需接触
        platform.claude.com
    end note
```

**OAuth 刷新的请求参数（逆向自 Claude Code 客户端）**：

```
POST https://platform.claude.com/v1/oauth/token
Body: {
  grant_type: "refresh_token",
  refresh_token: <token>,
  client_id: "9d1c250a-e61b-44d9-88ed-5944d1962f5e",
  scope: "user:inference user:profile user:sessions:claude_code ..."
}
```

## 五、项目目录结构

```
.
├── cmd/
│   └── gateway/            # 二进制入口
│       └── main.go         # 仅调用 cli.Execute()
├── internal/
│   ├── auth/               # 客户端认证（x-api-key / Bearer token）
│   ├── cli/                # Cobra 命令定义
│   ├── config/             # YAML 配置加载与验证
│   ├── logger/             # 结构化日志 + 审计日志
│   ├── oauth/              # OAuth Token 生命周期管理
│   ├── proxy/              # 反向代理服务器
│   └── rewriter/           # 请求体/请求头重写引擎
├── docs/                   # 项目文档
├── scripts/                # 辅助脚本
├── config.example.yaml     # 配置文件模板
├── Dockerfile              # Docker 构建
├── Makefile                # 构建/测试/运行命令
└── go.mod                  # 模块: ai/gateway
```

## 六、Go 版与 TypeScript 版差异

| 维度 | TypeScript 版 | Go 版（当前） |
|------|--------------|---------------|
| 运行时 | Node.js | 原生二进制 |
| 启动命令 | `npm start config.yaml` | `gateway serve config.yaml` |
| 包管理 | npm | Go modules |
| 构建产物 | JavaScript 源码运行 | 单文件二进制 |
| 镜像体积 | ~200MB | < 15MB |
| CLI 框架 | 无（手动解析 argv） | Cobra |
| 测试框架 | Node assert | Go testing |
